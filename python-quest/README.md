# Python Quest — مدينة الأكواد

منصة تعليم بايثون تفاعلية بالعربية والإنجليزية، مبنية على **كتاب البايثون بالعربي — المهندس حسن صفوان حجار** المرفق. مشروع محلي قابل للفتح والتعديل في Visual Studio Code.

## التشغيل السريع على Windows

1. فك الضغط أولًا، ثم افتح المجلد `python-quest` باستخدام **File → Open Folder** في VS Code.
2. افتح **Terminal → New Terminal** داخل المجلد الذي يحتوي `app.py`.
3. شغّل:

```powershell
py app.py
```

إذا لم يتوفر الأمر `py`، استخدم:

```powershell
python app.py
```

4. افتح `http://127.0.0.1:8000` في Chrome أو Edge أو Firefox حديث.
5. لإيقاف الخادم اضغط `Ctrl+C` في الطرفية.

يتطلب الخادم **Python 3.10 أو أحدث**. لا يحتاج إلى pip أو Node أو npm أو مفاتيح API. لا تفتح `index.html` بالنقر المزدوج ولا تستخدم Live Server وحده؛ الواجهة تحتاج إلى خادم Python المرفق. يمكن أيضًا تشغيل `start_windows.bat`.

على macOS وLinux:

```bash
python3 app.py
```

إذا كان المنفذ مستخدمًا:

```bash
python app.py --port 8001
```

ثم افتح `http://127.0.0.1:8001`.

## ما يحتويه المشروع

- 27 فصلًا حسب ترتيب المحتوى الفعلي، من المقدمة حتى JSON.
- 177 درسًا مجمّعًا بحسب المفاهيم، و704 أنشطة تدريبية. بعض العناوين الفرعية المتقاربة جُمعت في درس واحد؛ ليست هناك دعوى بأن كل فقرة في الكتاب أصبحت درسًا مستقلًا.
- شرح عربي مراجع، وترجمة إنجليزية للشرح والواجهة، مع RTL/LTR وخط Noto Sans Arabic مضمّن محليًا.
- نسخة PDF الأصلية كاملة، و169 صورة صفحة مقروءة داخل الموقع؛ تحفظ الألفاظ والتنسيق الأصليين دون تشويه استخراج النص.
- النص التعليمي أعلى الدرس **صياغة مبسّطة**، وليس نقلًا حرفيًا. النص الحرفي متاح عبر «اقرأ النص الأصلي». الكتاب الأصلي عربي ولم تُنشأ ترجمة حرفية إنجليزية كاملة له.
- أربعة أنماط للدروس البرمجية: توقّع الناتج، أكمل الرمز، رتّب الأسطر، اكتب الكود. الدروس النظرية لها ثلاثة أسئلة اختيار مع تفسير.
- بعض الأنشطة تتدرّب على المثال نفسه بطرق مختلفة؛ الرقم 704 عدد الأنشطة، وليس عدد المشكلات المستقلة تمامًا.
- تشغيل Python حقيقي داخل Web Worker باستخدام Pyodide المضمّن. لا يُنفّذ كود الطالب على خادم الجهاز.
- تفسير الأخطاء، تلميحات، محاولات غير محدودة، محطة مرئية تضيء عند الحل، نقاط لا تتضاعف بتكرار الإجابة.
- حفظ محلي للزائر، أو حساب محلي مع حفظ في SQLite؛ مراجعة الأخطاء غير المحلولة، حفظ المسودات والملاحظات، وتقارير JSON وCSV.

## العمل دون إنترنت

خطوط الواجهة ومحرّك Pyodide وملفات WebAssembly والكتاب موجودة داخل المشروع. بعد فك الضغط وتشغيل الخادم لا يعتمد المسار الأساسي على CDN أو شبكة خارجية. فتح محرّك Python أول مرة قد يحتاج عدة ثوانٍ. لا تحذف مجلد `static/vendor` لتقليل الحجم.

الملفات التي ينشئها الطالب في تمارين `open()` موجودة في نظام ملفات افتراضي داخل المحرّك، لا في ملفات Windows. تُعاد تهيئة المحرّك عند تغيير التمرين. المسودات والنتائج محفوظة خارج هذه المساحة الافتراضية.

## الحسابات والحفظ

وضع الزائر يحفظ في المتصفح نفسه. الحساب المحلي يحفظ في `data/progress.sqlite3`، ويمكن تسجيل الدخول إليه من المتصفح الذي يصل إلى الخادم نفسه. لا توجد مزامنة سحابية. تقدّم الزائر منفصل عن الحساب ولا يُرحّل تلقائيًا. احتفظ بنسخة من قاعدة البيانات بعد إيقاف الخادم إذا أردت نقل حساباتك.

كلمات المرور مشتقة باستخدام PBKDF2-HMAC-SHA256 وملح عشوائي؛ الجلسات تستخدم cookies من نوع HttpOnly وSameSite. طلبات التعديل للحسابات تتحقق من CSRF ومن Origin.

```text

  app.py                       خادم HTTP وAPI والمستخدمون والتصحيح والحفظ
  data/curriculum.json          المنهج المهيكل ثنائي اللغة
  static/index.html            الهيكل الدلالي
  static/style.css             التصميم المتجاوب والخط والروبوت
  static/app.js                التجربة التفاعلية وإدارة الحالات
  static/worker.mjs            تشغيل Python في Web Worker
  static/vendor/pyodide/       المحرّك المثبّت محليًا، الإصدار 0.27.7
  static/fonts/                الخط ورخصته
  static/book/                 الكتاب الأصلي وصور صفحاته
  tools/build_curriculum.py    بيانات التأليف وتوليد الأنشطة ونتائجها المرجعية
  tests/test_app.py             اختبارات المنهج والخادم
  docs/                       تحليل الكتاب والبنية ودليل العرض والتحقق
```

## الاختبارات

من المجلد الرئيسي:

```bash
python -m unittest discover -s tests -v
```

تُشغّل كل أمثلة المنهج ونسخها الاختبارية، وتتحقق من النتائج، ومراجع الصفحات، والحسابات، وعزل التقدّم، ومنع تكرار النقاط، وCSRF ومسارات الملفات. لا تتطلب اختبارات Python تثبيت مكتبات إضافية.

يمكن فحص صياغة JavaScript إذا كان Node مثبتًا، لكنه غير مطلوب لتشغيل المشروع:

```bash
node --check static/app.js
node --check static/worker.mjs
```

## تعديل المحتوى

للتعديل السريع حرّر `data/curriculum.json`، ثم أعد تشغيل الخادم. للتعديل القابل لإعادة البناء حرّر تعريفات `L(...)` و`T(...)` في `tools/build_curriculum.py` ثم:

```bash
python tools/build_curriculum.py
python -m unittest discover -s tests -v
```

الباني ينفّذ **أمثلة مرجعية موثوقة** لحساب النتائج. لا تمرّر إليه كودًا مجهول المصدر. إعادة البناء تستبدل ملف المنهج؛ احتفظ بمعرّفات الدروس ثابتة بعد بدء استخدام قاعدة بيانات فعلية، لأن التقدّم مرتبط بها.

## نطاق الإصدار وحدوده

هذا تطبيق تعليمي محلي قابل للعرض والتطوير، وليس منصة استضافة إنتاجية أو نظام امتحانات رسميًا. نتيجة تشغيل الكود تُحسب في المتصفح وترسل للحفظ؛ يمكن لمستخدم تقني تعديل طلباته. لا تستخدم هذا المسار وحده لمنح درجات رسمية. يلزم خادم تقييم معزول واختبارات مستقلة وتدقيق أمان قبل النشر متعدد المستخدمين. خادم مكتبة Python القياسية مناسب هنا لتسهيل التشغيل المحلي؛ لا تعرضه مباشرةً للإنترنت.

لا يوجد مساعد ذكاء اصطناعي أو اتصال بخدمة مدفوعة. الشروح والتلميحات معدّة مسبقًا، وشرح أخطاء التنفيذ قائم على نوع الاستثناء. لا توجد لوحة إدارة مرئية أو محرّر متعدد الملفات أو نظام شهادات. يمكن توسيعها لاحقًا، ولم تُعرض أزرار وهمية لها.

لا يمكن ضمان انعدام الأخطاء. راجع `docs/VALIDATION.md` لما اختُبر بالفعل، و`docs/BOOK_ANALYSIS.md` لفروق المصدر والتنبيهات.
