# التصميم التقني

## تدفق التعلّم

الواجهة تحمل المنهج من `/api/curriculum`. الدرس يربط شرحًا عربيًا وإنجليزيًا بنطاق صفحات الأصل. يحصل الطالب على تمرين، ثم تفسير للنتيجة، ثم حفظ للمحاولة. النقاط مشتقة من عدد التمارين المختلفة التي أُجيب عنها إجابة صحيحة.

## توزيع المسؤوليات

| الطبقة | التقنية | المسؤولية |
|---|---|---|
| العرض | HTML + CSS | اتجاه النص، الخط المحلي، المراحل، المحطات، الكتاب |
| التفاعل | JavaScript | التمرين، الترجمة، التنقّل، المسودات، الحفظ المحلي |
| تشغيل الطالب | Pyodide / Web Worker | Python حقيقي ونظام ملفات افتراضي؛ إيقاف العامل عند تجاوز الوقت |
| التطبيق | Python standard library | حسابات، جلسات، CSRF، تصحيح الأسئلة المحددة، التسجيل |
| البيانات | SQLite | مستخدمون وجلسات ومحاولات وإنجازات وملاحظات ومسودات |
| التأليف | Python + JSON | تعريف الدروس والأسئلة وإنتاج النتائج المرجعية |

## الجداول

| الجدول | المفتاح | المحتوى |
|---|---|---|
| users | id | اسم فريد، ملح وتجزئة مشتقة لكلمة المرور |
| sessions | token | المستخدم وCSRF والانتهاء |
| attempts | id | المستخدم والدرس والتمرين والإجابة والوقت والصحة |
| solved | user_id, lesson, exercise | قيد فريد يمنع احتساب النقاط مرتين |
| drafts | user_id, lesson | آخر مسودة |
| notes | user_id, lesson | ملاحظة الطالب |

## API

| المسار | الطريقة | الاستخدام |
|---|---|---|
| /api/curriculum | GET | المنهج |
| /api/session | GET | حالة الحساب |
| /api/register | POST | إنشاء حساب محلي |
| /api/login | POST | تسجيل الدخول |
| /api/logout | POST | حذف الجلسة |
| /api/progress | GET | التقدّم والملاحظات والمسودات |
| /api/export | GET | نسخة بيانات التقدّم |
| /api/attempt | POST | تسجيل المحاولة ومنح النقاط مرة واحدة |
| /api/note | POST | حفظ ملاحظة |
| /api/draft | POST | حفظ الكود |

ترسل طلبات POST كائن JSON. الطلبات المصادق عليها تتضمن csrf. لا يوجد CORS مفتوح؛ النطاق المختلف مرفوض. لا تُسجل كلمات المرور أو الإجابات في سجل طلبات HTTP.

## نموذج تقييم الكود

تشغّل الواجهة الكود في متصفح المتعلّم، وتلتقط stdout والأخطاء. تقارن الناتج مع المرجع وتتحقق من وجود اسم/رمز المفهوم المطلوب باستخدام tokenizer؛ هذا فحص تربوي بسيط وليس برهانًا على خوارزمية الحل. ترتيب الأسطر يقبل الترتيب الذي يعمل ويحقق الناتج، وليس ترتيبًا حرفيًا وحيدًا. لا تُحذف الفراغات الطرفية المهمة من الناتج؛ تُوحّد نهايات الأسطر فقط.

تبدأ المهلة البالغة 8 ثوانٍ بعد تحميل المحرّك. زر الإيقاف ينهي العامل، ولا يجمّد حلقة لا نهائية واجهة المتصفح. هناك حد لحجم الكود وخرج النص. لا يمثل ذلك عزلًا كاملًا عن أصل الويب: يمكن للكود المتقدم استخدام تكامل Pyodide مع JavaScript. لذلك لا تشغّل شيفرات مجهولة نيابة عن مستخدم آخر ولا تنشر هذا التصميم كنظام تقييم عدائي متعدد المستأجرين.

## قرارات تصميمية

- تشغيل محلي بلا تثبيت dependencies لتقليل أعطال الإعداد في VS Code.
- تجميع الموارد بدل CDN لضمان التشغيل دون إنترنت.
- صور الكتاب بدل استخراج آلي مشوّه للاتجاه العربي أو علامات الكود.
- تمييز النص الأصلي عن الشرح المعاد صياغته والتمرين الجديد.
- عدم حجب الدروس: يمكن للطالب الرجوع أو الاستكشاف، والنقاط لا تعاقب الخطأ.
- الحفاظ على الشروح والتمارين باللغتين، مع إبقاء صورة المصدر العربي كما هي.

## توسعات قبل استضافة عامة أو تقييم أكاديمي رسمي

خادم إنتاجي؛ HTTPS؛ تحديد معدل طلبات الدخول؛ إعادة تعيين كلمات المرور؛ إدارة المدرّسين؛ إتاحة نصية كاملة للكتاب لبرامج قراءة الشاشة بعد مراجعة بشرية؛ اختبار متعدد المدخلات لكل مسألة برمجية؛ حاويات تنفيذ خارج خادم التطبيق؛ تقييم تربوي تجريبي مع طلاب حقيقيين. هذه ليست ميزات مكتملة في هذا الإصدار.
