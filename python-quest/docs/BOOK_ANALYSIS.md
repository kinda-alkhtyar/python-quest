# تحليل الكتاب وربط المنهج

المصدر: **كتاب البايثون بالعربي — المهندس حسن صفوان حجار**، النسخة المرفقة `downloadfile.pdf`، 169 صفحة PDF. أرقام الصفحات في التطبيق هي أرقام PDF الفعلية، وليست الرقم المطبوع أسفل الصفحة؛ المقدمة تبدأ في PDF 3 وتحمل رقمًا مطبوعًا 1.

## نتائج التحليل

- يحوي المتن 27 فصلًا فعليًا؛ يبدأ بالمقدمة وينتهي بمعالجة JSON.
- الفهرس المضاف في PDF 2 لا يطابق تسلسل المتن؛ لذلك لم يُستخدم لبناء المنهج. مثلًا الفصل الرابع الفعلي هو التعليقات، والثامن السلاسل النصية، والخامس عشر الشروط.
- استُخرج النص لتحديد العناوين، لكن استخراج PDF يعكس بعض الأقواس وعلامات التنصيص ويشوّه بعض أشكال العربية؛ لم يُعرض هذا الاستخراج بوصفه شرحًا موثوقًا.
- حُفظ PDF دون تعديل، وصُوّرت صفحاته كلها. يُتاح النص الأصلي عبر قارئ الكتاب، وروابط الصفحات في الدروس.
- جُمعت الموضوعات المتقاربة في 177 درسًا. لا يعني ذلك وجود تمرين مستقل لكل سطر أو فقرة من الأصل.
- لكل درس برمجي أربعة أنشطة؛ للدروس النظرية ثلاثة أسئلة. بعض الأنشطة تشترك في المثال المرجعي للتدرّب بطرق مختلفة.

## تنبيهات لغوية وتقنية عولجت في الشرح

| الموضع | التنبيه | المعالجة |
|---|---|---|
| الفهرس، ص 2 | عناوين لا توافق المتن | اعتماد المتن وربط الصفحات |
| المقارنة، ص 7 | إدراج HTML مع لغات برمجة عامة | توضيح أنها لغة توصيف |
| التثبيت، ص 18 | ظهور شرطة غير ASCII في أمر الإصدار | كتابة `python --version` |
| التعليقات، ص 23 | استعمال التنصيص الثلاثي كتفسير للتعليقات | توضيح أنه ينشئ نصًا وقد يكون توثيقًا، لا تعليقًا نحويًا مستقلًا |
| السلاسل، ص 43 | وصف النص بأنه مصفوفة بايتات | توضيح أن `str` تسلسل نقاط Unicode غير قابل للتعديل |
| طرق النص، ص 45 وما بعدها | تفاوت حالة الأحرف أو انعكاس الصياغة في الاستخراج | استخدام أسماء methods الصحيحة وفحص الأمثلة بالتنفيذ |
