## التحقق في متصفح Chromium

- معاينة الخريطة العربية والخط والألوان واتجاه الكود بصريًا.
- فتح درس الطباعة، وتحميل المثال وتشغيل Python المضمّن: ناتج صحيح وزيادة 10 XP.
- إدخال اسم غير معرّف: ظهر شرح NameError بالعربية.
- تبديل الواجهة والشرح إلى الإنجليزية.
- التفاعل مع ترتيب أسطر المثال وتشغيله.
- تشغيل مثال كتابة ملف افتراضي ثم قراءته: ظهر Hello، وأضاءت محطة الكود، وحُفظ الإنجاز.
- تشغيل حلقة غير منتهية: أُوقف العامل بعد ثماني ثوانٍ، وظهر تفسير واضح، وعاد زر التشغيل متاحًا.

الاختبارات الآلية شُغّلت باستخدام Python 3.12 في بيئة Linux. التشغيل على Windows موثّق ومصمم للاعتماد على المكتبة القياسية، لكنه لم يُجرَّب على جهاز Windows فعلي. لم يُجرَّب كل تمرين يدويًا في المتصفح، ولم يجرِ اختبار مستخدمين تربوي أو تدقيق أمان إنتاجي. التصميم يتضمن نقاط توقف للشاشات الصغيرة، لكن لا ندّعي اختبارًا فعليًا على جميع أجهزة الهاتف.
